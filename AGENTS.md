# Working on Agentic Research Workspace

This is the public software repository. Start with README.md,
docs/development/README.md and docs/public-roadmap/README.md. Future designs
are not implemented features. Keep changes bounded and explain validation.

- Preserve source-local assertions, stable identity, exact evidence routes and
  explicit potential cross-source relationships. Do not adjudicate science.
- Keep human-readable and agent-readable interfaces equally discoverable.
- Keep original source material and research runs outside this checkout.
  Never add private working data, credentials, local paths or private history.
- Do not change frozen non-prose artifacts under reference_mapping_graph or
  the four approved screenshots. New datasets need a separate publication review.
- Use uv and Python 3.12+. Run tests, lint, formatting, types, build and the
  public-tree checks documented in CONTRIBUTING.md.
- Use a focused branch and targeted commits. Review the full diff before a push.
  Publication, tags and releases need explicit owner authority.
- Do not run live model extraction as a test; use labelled synthetic fixtures.
- Record technical decisions and status in public docs. Do not copy private
  planning records into this repository.

The working system and its eventual published research pack are distinct.
Literature mapping is the first implemented part of the larger workspace.
