# Third-party rights and dataset status

The Apache-2.0 license in this repository applies to original project code and
documentation. It does not grant rights in third-party papers, source assets,
bibliographic metadata supplied by others, or source-derived research records.

## This public baseline

The release contains bibliographic metadata fields and aggregate counts under
a conservative publication policy. It contains no source PDFs and no
evidence-bearing private graph. The bundled graph demonstration is invented
for this repository and does not quote, summarize, or model a real paper.

The private inventory has 53 logical sources and 54 assets. Two source
registrations record a CC-BY 4.0 notice; redistribution rights for the other 51
sources have not been assessed. To keep one consistent boundary, this baseline
publishes metadata only for every registered source and does not redistribute
any asset.

## Dataset license

No dataset license is granted for the withheld graph, its source-derived
records, or source assets. Publication of aggregate measurements is not a
release of the underlying dataset. A future data release requires a separate
rights review, scope decision, license, and manifest.

The machine-readable inventory is
[`reference_mapping_graph/rights-inventory.yaml`](reference_mapping_graph/rights-inventory.yaml),
and the operative release policy is
[`reference_mapping_graph/publication-policy.yaml`](reference_mapping_graph/publication-policy.yaml).
