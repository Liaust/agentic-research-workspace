# v0.1.0-alpha.1 — Experimental Literature Mapping Baseline

The first software release of **Agentic Research Workspace** establishes a
public development baseline. Literature mapping is the first working surface
of a longer-term workspace for researchers and agents.

**Pre-release; source checkout required.** Python package metadata reports
`0.1.0a1`. Interfaces and formats may change during the alpha series.

## Included

- Experimental literature-map coordinator, schemas and protocols.
- Evidence, atoms, reasoning moves and argument threads as source-local records.
- Deterministic record validation, Markdown round trips and graph compilation.
- Explicit graph search and one-hop exploration with human and JSON output.
- Existing two-source potential-relationship fixture with inspectable provenance.
- A new original synthetic source-to-graph walkthrough: six records, nine links,
  zero model calls, source hashes and a reproducible output receipt.
- Frozen aggregate results and four approved illustrations of a private
  superdeterminism testing corpus; no underlying source assets or private graph.
- Public-only regression tests, CI, contribution guidance and release checks.
- An outcome roadmap and research-pack design questions that distinguish
  present software from future capabilities.

## Try the release

```sh
git clone --branch v0.1.0-alpha.1 https://github.com/Liaust/agentic-research-workspace.git
cd agentic-research-workspace
uv sync --frozen --all-groups
uv run research-map --version
uv run python -m research_map.demo --output build/synthetic-study
uv run research-map explore --id LIB-903:atom:causal-limit --graph build/synthetic-study/graph.json --json
```

Requires Git, Python 3.12+ and uv. The public walkthrough and tests require no
model credentials or private files. The walkthrough validates authored records;
it is not a demonstration of live model extraction.

## Validation and release identity

The release is gated on the full public suite, lint/format/types, package build,
synthetic command replay, public-tree checks and historical snapshot verification.
GitHub CI checks Python 3.12 and 3.13 against the released source commit.

The attached software manifest identifies that commit, its public files and
their hashes. The older manifest in `reference_mapping_graph/baseline-v1`
continues to describe the September aggregate export; it is not overwritten by
software releases. Neither manifest certifies scientific correctness or rights
to unpublished third-party material.

## Known limitations

- Source checkout is the supported installation. Runtime resource discovery
  is not yet self-contained for standalone wheel installation.
- The graphical viewer shown in README screenshots is not bundled.
- Real-corpus/model execution requires additional configuration, originals and
  source review. The public suite does not establish extraction fidelity.
- Later long-form ingestion, checkpoint recovery and quality-policy refinements
  are not all integrated into this baseline.
- Lexical search is not semantic retrieval. Potential relationships are not
  scientific verdicts; schema validity is not source fidelity.
- The historical testing corpus has uneven audits. Published counts measure
  retained output, not correctness or complete coverage.
- The living workspace, project-wide coordinator and research-pack publisher
  remain design-stage work.
