# Changelog

## 0.1.0-alpha.1 — 2026-09-15

First experimental GitHub software release: **Literature Mapping Baseline**.
Python package metadata uses the equivalent version `0.1.0a1`.

- Establish ongoing public development with public-only CI, contributor
  templates, a repository guide and release checks.
- Add a model-free walkthrough from original synthetic source text through
  six authored records to a validated graph, with reproducible hash receipts.
- Rewrite README and roadmap to distinguish the working mapper, design-stage
  living workspace and future research-pack publisher.
- Publish the research-pack question catalogue and workspace/publication boundary.
- Keep the historical aggregate export intact and independently verifiable;
  add separate software-tree verification and release manifests.
- Align CLI version reporting with installed package metadata.
- Make all synthetic publication-test Git revisions deterministic across dates;
  preserve the historical scanner and its rejection assertions unchanged.

This is a source-checkout release. The screenshots' viewer, self-contained
package installation and later long-form ingestion/recovery work are not
bundled. No new real corpus or scientific findings are published.

See [release notes](docs/releases/v0.1.0-alpha.1.md) for scope and limitations.
